格式要求（必须严格遵守）

  • 文件格式：.xlsx（不支持 .xls / .csv）
  • 第一行表头必须完全一致（共 {{ required_headers|length }} 列）：

{% for h in required_headers %}{{ h }}{% if not forloop.last %} · {% endif %}{% endfor %}

  • 从第 2 行起为题目，最多 {{ max_rows }} 道
  • 题型：推荐在 Excel 模板下拉框中直接选择 单选题、多选题、判断题、简答题（亦兼容填写 single / multiple / judgment / short_answer）
  • 单选：四选项必填，正确答案单个字母 A/B/C/D
  • 多选：四选项必填，正确答案逗号分隔且至少 2 项，如 A,C（须全部选对才得分）
  • 判断：选项 A/B 为正确/错误文字，正确答案 A 或 B
  • 简答：参考答案写在「选项A」列，多个可接受答案用 | 分隔
  • 词云：选项列可留空，无标准答案
  • 时限秒：5–120 的整数
